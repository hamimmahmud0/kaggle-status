Make a Kaggle status plugin for gnome.

You can take inspiration from this repo: `https://github.com/dvdstelt/ClaudeCodeUsage.git`

Requirements:
- clean UI
- multi-account support using token
- check which session are running
- show combined quota in panel (all account) (in donut ring must like claudecodeusage)
- option for to see individual quota
- browse kernels and run kernel (make sure i can ran kernel of one account with other) and also show output
- in panel show number of kernels currently running
- a good setting menu for maximum customization
- .token dir contains token do not read it but use it.
- ergonomic UI design.
